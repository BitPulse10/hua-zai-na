# 花在哪 · 单机预算记账

手机优先的本地记账应用，不需要账号、服务器或外部依赖。浏览器版将账本保存在 `localStorage`；Android 版通过本机账本桥读写 JSON，并以原子文件保存。首次启动不会填入示例工资、钱包或消费。

## 打开和离线使用

- 电脑本地预览可直接打开 `index.html`。浏览器中的离线缓存需要安全上下文 HTTPS；Android 版使用 APK 内置页面资源，可离线运行，且不会注册网页 Service Worker。
- 页面打开、恢复到前台和定时检查时，会补齐错过的发薪周期与到期计划。关闭页面时不会后台执行或发送系统通知。
- 新安装会先完成工资与发薪日、首个钱包（或稍后添加）和设置摘要三步；工资、发薪日和钱包金额均从空白开始，确认“开始记账”后才建立首个发薪周期。未完成的引导草稿会单独保存并在下次打开时恢复。
- 页面使用设备本地时区。换浏览器或手机前，在“设置”导出 JSON 备份，再在新设备导入。清理浏览器站点数据会删除浏览器账本；Android 账本保存在应用本机数据中。
- Android 打包页面直接使用本目录的 `index.html`、`app.js` 和 `styles.css`。更新网页功能后需重新构建 Android 包。

## 三个页面

- **钱包**：显示本月到手工资、已分配、未分配和本月支出合计。点击钱包大卡片直接记即时消费；明细、编辑、删除始终可见，临时收入、转给其他钱包与停用/恢复收在卡片的“更多”中。公积金、医保与累计结余也显示在钱包首页。到期计划会出现在首页的待确认账单中，可确认或取消；确认前不会记入支出。
- **账单**：查看今日、本周、本月、年度、历史发薪周期和逐笔流水。月度按发薪周期，年度按发薪月份的周期起始月份归属；年度合计由 12 个发薪月份分项相加。报表总额注明含公积金、医保；分类金额分别显示钱包支出与公积金 / 医保支出。
- **设置**：填写每月到手工资，可设置发薪日与小时，或导入、导出备份。应用版本为 2.0.1；账本保存在当前浏览器或 Android 设备本机。

## 钱包、账户和余额

- **每月预算钱包**：预算从一个发薪日延续到下一个发薪日；每到发薪日恢复至设定金额，未用完的正余额会转入累计结余。本期重设也只调整这类钱包，历史消费仍保留。
- **长期储蓄钱包**：可设置“已储蓄额度”和“每月自动存入”。自动存入金额填 0 时不增加；填正数后，每个新发薪周期会从月工资分配并存入该金额，既有储蓄余额继续保留。调整金额从下个发薪周期生效；额外存入、消费或转入都不改变每月自动存入金额。
- **会员储值**：保存会员卡长期余额；充值与消费分别记账。
- **公积金和医保账户**：添加时为公积金设置每月个人和单位预计到账金额，为医保设置每月预计划入金额。自动发薪日到达后先登记预计到账，用户可按实际情况修正原记录（含修正为 0，表示本月未到账），也可登记一笔额外到账。手动开始新周期和本周期重置都不会增加账户金额。已存余额仍可登记消费；公积金也可提取到启用中的钱包。
- **累计结余**：每次新发薪周期会归集每月预算钱包的正余额；补记或删除历史消费后会重算对应周期结余。钱包停用期间不归集余额；恢复后首个新周期会保留恢复前余额并恢复设定额度，之后按正常周期规则归集。若回溯后结余不足，卡片会显示待补差额，并暂停新的消费和转出。余额可查看明细或转入长期储蓄钱包。
- **余额转入**：每月预算钱包只能转入其他每月预算钱包；长期储蓄钱包之间可互转，累计结余也可转入长期储蓄钱包。可填写全部或部分金额。转入只变更当前余额，不修改每月自动存入金额或其他未来周期计划。
- **额外存入**：长期储蓄钱包的额外存入增加当前余额，但不改每月自动存入金额；每月预算钱包的临时收入只增加当前余额，不改变下期额度。

## 计划消费与删除钱包

钱包明细可以添加一次、每月、每季度或每年的计划消费。到期后只生成待确认账单，不会自动扣款。首页和钱包明细均可逐笔确认真实消费或取消；确认时选择实际付款钱包、金额和日期。没有可选钱包时，账单仍可取消，或等新建钱包后再确认。

停用钱包会保留余额和历史、本期已分配额度不变，并暂停未来消费计划；恢复时只参加下一个新周期，不会补发本期额度，且会检查恢复后的计划分配是否超过月到手工资。删除钱包要求当前余额为 ¥0.00；有余额时可先记账或转出，也可停用保留。删除弹窗可把未来计划和未完成账单转交到启用中的其他钱包，或暂停计划并让待确认账单等待选择钱包。删除不释放本期已分配额，历史账单始终保留。

## 周期刷新

发薪日可设为每月 1–31 日、时间为 0–23 时；短月自动取当月最后一天。系统重新打开、回到前台或定时检查时处理到期周期，同一周期不会重复增加额度。

每月预算周期按发薪日计算。设置页的“手动调整周期…”提供两种操作，确认按钮在左侧、取消在右侧：

- **手动开始新周期**：结束当前周期并保留快照；每月预算恢复到设定金额，长期储蓄按每月自动存入金额增加余额，未用完的每月预算转入累计结余。停用钱包的负余额会归零并转成待处理超支。公积金、医保和会员储值不变。刷新前会预览余额、结余和超支变化；历史待确认账单保留。
- **重新设定本期额度**：不改周期日期，只重置每月预算钱包并记录预算金额调整；长期储蓄和会员储值余额、公积金与医保账户余额不变。

有启用中的每月预算钱包余额为负时，本周期重置会被拦截；可先补齐或开始新周期登记缺口。新周期超支需在首页逐笔补齐，补齐只调整余额，不会计入消费。

## 数据兼容

浏览器会迁移旧版 `liuyibi-budget-v1` 账本及 v2、v3、v4 备份；当前使用 v5 数据格式，包含钱包停用、周期超支与结余排除信息。旧 `savings` 类型钱包在加载或导入时会转为长期储蓄钱包，并将每月自动存入设为 0；保留原钱包 ID、余额流水、停用状态和历史周期快照，不补记余额。迁移时保留旧工资设置对应的实发到手金额。

正式版与旧版 Android 应用并存，正式版不会自动读取旧版应用数据库；如需保留旧账本，请先保留旧版应用，不要卸载或清除其数据。只有找回旧版签名证书，并构建使用匹配应用 ID 与证书的兼容包后，才能转换旧账本并导出 JSON，再将 JSON 导入正式版。已有网页 JSON 备份也可以直接导入正式版。

导入文件先完整校验，再由用户确认替换当前数据。设置页会显示最近一次成功的 JSON 备份导出时间；Android 取消导出时不会更新时间。浏览器或 Android 无法读取、写入账本时，页面会显示提示并保留上次成功保存的数据。
